# urban_cavemining – מערכת כרייה מלאה למערה (URBAN RP)

מערכת כרייה מלאה ל-FiveM שבנויה בדיוק סביב המפה **K4MB1 – Cave Mining** (MLO במחצבה של Davis Quartz, ליד סנדי שורס,
`2889.01, 2664.66, 41.72`). הסקריפט מפזר את העפרות והגבישים של K4MB1 ב-35 נקודות בתוך המערה, ומוסיף את כל מה שמסביב:
כלים, כבשן, פיצוח אבנים, שולחן תכשיטים, שטיפת אבנים, חיפוש זהב, חנות, קונה, רמות וקסדה עם פנס.

> ה-MLO עצמו (המודל התלת-ממדי) הוא מוצר בתשלום של K4MB1 ונקנה אצלם. הריסורס הזה הוא הסקריפט שמפעיל אותו,
> ויש גם `Config.PropSet = 'vanilla'` שעובד בלי הפרופים שלהם. גרסה משלנו של המערה נבנית ב-Blender (ראו `../blender`).

## מה יש בפנים

| מערכת | מה זה עושה |
|---|---|
| **עפרות בשרת** | 35 נקודות, השרת מחליט מה נמצא בכל נקודה (פחם, נחושת, ברזל, בדיל, עופרת, בוקסיט, זהב, אודם, ברקת, ספיר, יהלום), כמה "חיים" נשארו ומתי זה צומח מחדש. כולם רואים אותו דבר. |
| **3 כלים** | מכוש → מקדחה (אוכלת ראשי מקדחה) → לייזר (קרן אדומה). הסקריפט בוחר לבד את הכלי הכי טוב שיש לך. |
| **רמות כרייה** | 10 רמות, XP נשמר לכל דמות (KVP – בלי SQL). כל רמה = כרייה מהירה יותר + סיכוי לשלל כפול. גבישים דורשים רמה 5, יהלום רמה 7. |
| **כבשן** | עפרה + פחם → מטילים (נחושת, ברזל, בדיל, עופרת, אלומיניום, פלדה, ארד, זהב). |
| **פיצוח אבנים** | אבן → שלל אקראי (עפרות / אבני חן) עם ראש מקדחה. |
| **שולחן תכשיטים** | ליטוש אבני חן (סיכוי לשבור) + הכנת טבעות, שרשראות ועגילים. |
| **מחבת זהב** | בתוך מים: שטיפת אבנים (אבני חן / גושי זהב) או חיפוש זהב. |
| **חנות + קונה** | NPC-ים בתוך המערה, מחירים בקונפיג, כלים מתקדמים נעולים לפי רמה. |
| **אבק מהרגליים** | כל צעד בתוך המכרה מעיף חול / עפר (הליכה, ריצה, ספרינט). |
| **עבודת כורה** | מנהל עבודה בכניסה: להיות כורה / לעזוב. מחליף עבודה (למשל ממשטרה). |
| **קסדת כורים** | "שימוש" בקסדה = כובע על הראש + פנס שעוקב אחרי המצלמה עם צללים. |
| **עורך במשחק** | `/caveeditor` – מוסיפים / מוחקים נקודות עפרה עם העכבר, נשמר ל-`data/positions.json`. |
| **אנטי-צ'יט** | כל פעולה נבדקת בשרת: מרחק, פריטים, כסף, וזמן (אי אפשר לסיים פעולה לפני שהטיימר נגמר). |

תמיכה: **qbx_core / qb-core / es_extended**, **ox_inventory / qb-inventory (ps / lj) / ESX**, **ox_target / qb-target** –
ואם אין target, יש הנחיות `[E]` של ox_lib. שפות: **עברית + אנגלית**.

## דרישות

- [`ox_lib`](https://github.com/overextended/ox_lib)
- פריימוורק: qbx_core / qb-core / es_extended
- המפה של K4MB1: `k4mb1-caveprops` + `k4mb1-cavemining` (או `Config.PropSet = 'vanilla'`)

## התקנה

1. להעתיק את `urban_cavemining` לתיקיית ה-resources.
2. ב-`server.cfg`, **אחרי** ox_lib, הפריימוורק, האינוונטורי וה-MLO:
   ```cfg
   ensure k4mb1-caveprops
   ensure k4mb1-cavemining
   ensure urban_cavemining
   ```
3. להוסיף את הפריטים (45 פריטים, נוצרו אוטומטית מ-`shared/items.lua`):
   - **ox_inventory** – להדביק את `install/ox_inventory_items.lua` בתוך `ox_inventory/data/items.lua`
   - **qb-core** – להדביק את `install/qb_items.lua` בתוך `qb-core/shared/items.lua`
   - **ESX** – להריץ את `install/esx_items.sql` על הדאטהבייס
4. להעתיק את `install/images/*.png` לתיקיית התמונות של האינוונטורי
   (`ox_inventory/web/images` או `qb-inventory/html/images`).
5. ריסטארט לשרת.

## עבודת כורה (במקום משטרה)

ליד פתח המכרה עומד **מנהל העבודה** (NPC). מכוונים עליו ובוחרים **"להיות כורה"**. זה מחליף לך את העבודה
(למשל ממשטרה) לכורה. **"לעזוב את המכרה"** מחזיר ל-`unemployed`.

1. מוסיפים את העבודה לפריימוורק (פעם אחת):
   - **qbx_core** – להדביק את `install/qbx_jobs.lua` בתוך `qbx_core/shared/jobs.lua`
   - **qb-core** – להדביק את `install/qb_jobs.lua` בתוך `qb-core/shared/jobs.lua`
   - **ESX** – להריץ את `install/esx_jobs.sql`
2. ריסטארט לשרת.
3. הולכים למנהל העבודה בכניסה, או כאדמין: `/setjob [ה-ID שלך] miner 0` (אותה פקודה ב-qb / qbx / ESX).

השם בעבודה בעברית (כורה, כורה מתחיל, כורה בכיר, מנהל המכרה), כמו שהוא יופיע ב-HUD.
ברירת המחדל: **כל אחד יכול לכרות** (`Config.Job = nil`). כדי שרק כורים יוכלו לכרות: `Config.Job = 'miner'`.

## איך משחקים

1. קונים **מכוש** (וקסדה) אצל ה-NPC של ציוד הכרייה בכניסה לבית המלאכה.
2. נכנסים למערה, מכוונים על עורק ובוחרים **כרה**. כל מכה מורידה חיים לעורק, וכשהוא נשבר מקבלים את העפרה (ולפעמים אבן).
3. **כבשן** – מתיכים עפרה + פחם למטילים.
4. **פיצוח אבנים / מחבת זהב** – הופכים אבנים לאבני חן וזהב.
5. **שולחן תכשיטים** – מלטשים אבני חן ומכינים תכשיטים.
6. מוכרים הכל ל**קונה** (תכשיטים שווים הכי הרבה).

| עורק | רמה | כלים | נותן |
|---|---|---|---|
| פחם | 1 | כל הכלים | `coal` |
| נחושת / ברזל | 1 | כל הכלים | `copperore` / `ironore` |
| בדיל / עופרת | 2 | כל הכלים | `tinore` / `leadore` |
| בוקסיט | 3 | כל הכלים | `bauxite` |
| זהב | 4 | כל הכלים | `goldore` |
| אודם / ברקת / ספיר | 5 | מקדחה / לייזר | `uncut_ruby` / `uncut_emerald` / `uncut_sapphire` |
| יהלום | 7 | לייזר | `uncut_diamond` |

## פקודות

| פקודה | מי | מה |
|---|---|---|
| `/mininglevel` | כולם | מראה רמת כרייה ו-XP |
| `/caveeditor` | אדמין | עורך נקודות: `E` הוספה, `G` מחיקה, גלגלת = סיבוב, `Backspace` יציאה |
| `/cavereset` | אדמין | כל העפרות צומחות מחדש עכשיו |
| `/cavexp [id] [amount]` | אדמין | נותן / מוריד XP |
| `/cavecoords` | אדמין | מדפיס ומעתיק את המיקום שלך (לכניסה / לנקודות) |

ההרשאה היא `group.admin` (משתנה ב-`Config.Admin.group`).

## הגדרות חשובות (`config.lua`)

- `Config.Locale` – `'he'` / `'en'`
- `Config.Job` – להגביל לעבודה (למשל `'miner'`), `nil` = כולם
- `Config.PropSet` – `'k4mb1'` או `'vanilla'`
- `Config.Respawn` – כמה זמן עד שעורק צומח מחדש
- `Config.Ores` – משקל הופעה, חיים, רמה, כלים ושלל לכל סוג
- `Config.Tools` – כוח, מהירות, סיכוי שבירה, אנימציות וסאונדים
- `Config.Smelting`, `Config.Cracking`, `Config.Washing`, `Config.Panning`, `Config.JewelCutting` – מתכונים ושלל
- `Config.Shop`, `Config.Buyer.prices` – כלכלה

כל המיקומים (חנות, קונה, כבשן, שולחנות, 35 הנקודות) נמצאים ב-`shared/locations.lua`.
