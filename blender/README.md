# מחולל מערת הכרייה ל-Blender

`cave_mine_generator.py` בונה ב-Blender מערת כרייה שלמה בסגנון **K4MB1 – Cave Mining**, מאפס, עם סקריפט אחד:

- **מעטפת המערה** – מנהרות ואולמות בסלע טבעי. בנוי משדה מרחק (SDF) + רעש סלע (כולל שכבות חדות) + Surface Nets,
  רצפות ישרות להליכה, פתח כניסה פתוח. ~120 אלף פוליגונים, רכיב אחד סגור, נורמלים לכיוון השחקן, UV,
  ועותק מופחת להתנגשויות (`Cave_Collision`).
- **סוגי אבנים** – חומר שכבות לפי גובה: אבן חול, גיר, גרניט (עם נקודות), בזלת וצפחה, עם סדקים, בליטות ואבק על הרצפות.
- **תמיכות עץ** – מסגרות (2 עמודים + קורה + תמוכות) כל ~4 מטר בכל מנהרה, בגובה שנמדד מול התקרה האמיתית.
- **מסילות + עגלות** – מסילה עם אדנים משתי הכניסות עד בית המלאכה והפיר הדרומי, 3 עגלות מלאות עפרה.
- **תאורה** – מנורות עבודה תלויות עם כבלים משתלשלים, שרשראות נורות באולמות, מגדלי פרוז'קטורים צהובים.
- **עורקי עפרה** – 35 עורקים בדיוק בנקודות שבהן הסקריפט של FiveM מספאון עפרות (נחושת, ברזל, זהב, בדיל, עופרת, בוקסיט, פחם).
- **אולם הגבישים** – עשרות אשכולות גבישים זוהרים (אודם, ברקת, ספיר, יהלום) עם אור צבעוני.
- **בית המלאכה** – כבשן לבנים עם ארובה ואש, 2 עמדות פיצוח, 2 שולחנות תכשיטים, דלפק חנות עם מדפים,
  שולחן קונה עם משקל ומטילי זהב, דק עץ, ארגזים וחביות.
- **קישוט** – נטיפים וזקיפים, סלעים, 300+ אבנים על הרצפה, צינור אוורור צהוב, פיגום וסולם למדף העליון.

## מיושר עם הסקריפט

הכל בנוי במרחב של FiveM: הנקודה `(0,0,0)` = ה-origin של ה-MLO (`2889.014, 2664.655, 41.72483`).
המנהרות עוברות דרך 35 נקודות העפרה של `fivem/urban_cavemining`, והמחולל בודק בעצמו
שכל נקודת אינטראקציה (35 עפרות + כבשן, שולחנות, NPC-ים) עומדת בחלל פתוח:

```
[cave] validation: 42/42 FiveM points stand in open cave
```

## הרצה

**בתוך Blender (4.0 ומעלה):** Scripting → Open → `cave_mine_generator.py` → Run Script (בערך דקה).

**בלי ממשק:**

```bash
blender -b -P cave_mine_generator.py -- --save cave_mine.blend --render previews/
# או עם מודול bpy:  pip install bpy==4.2.0
python cave_mine_generator.py --save cave_mine.blend --render previews/
```

צריך רק numpy (מגיע עם Blender), בלי תוספים. אפשר לשנות בראש הקובץ: `VOXEL` (רזולוציה), עוצמת הרעש,
וה-`NODES` / `EDGES` שקובעים את צורת המנהרות.

## ל-GTA (Sollumz)

1. להתקין [Sollumz](https://github.com/Sollumz/Sollumz) ב-Blender.
2. לחלק את `Cave_Shell` לכמה חלקים (לפי אזורים) ולהמיר כל חלק ל-Drawable עם shader של סלע (`normal_spec` / `terrain`).
3. `Cave_Collision` → Bound Composite (חומר: ROCK). לרהיטים – bounds פשוטים.
4. ליצור Archetype מסוג MLO עם Rooms + Portals (פורטל אחד בפתח המערה), למקם ב-origin שלמעלה, ולייצא ytyp + ymap.
5. להפעיל את `urban_cavemining` עם `Config.PropSet = 'vanilla'` (או עם הפרופים של K4MB1 אם יש).
