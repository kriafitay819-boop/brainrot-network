# מחולל מערת הכרייה ל-Blender (גרסה 2 – ריאליסטית)

`cave_mine_generator.py` בונה ב-Blender, עם סקריפט אחד ובלי תוספים, את כל המכרה בסגנון **K4MB1 – Cave Mining**:
מהקיר של המחצבה (בדיוק כמו בתמונה מהשרת) ועד אולם הגבישים בסוף.

## מה נבנה

**הכניסה במחצבה**
- קיר מחצבה של 11.5 מ' עם דרך (bench) למעלה וקיר נוסף מאחוריה, רצפת מחצבה, והמחצבה סגורה מסביב.
- שער מכרה מעץ: 2 מסגרות של קורות, קורות עגולות למעלה, קרשים מעל, שלט, חיזוקי ברזל.
- עגלת רציף (flatbed) על המסילה בחוץ, ערימת צינורות חלודים עם רצועות, חביות כחולות ושחורות,
  מכל אדום שוכב, 3 שירותים כימיים, סלעים, ושביל משאיות עם עקבות צמיגים עד הפתח.
- **המיקום של הכניסה הוא הגדרה אחת** (`ENTRANCE` בראש הקובץ). במשחק: נעמדים בפתח, `/cavecoords`,
  ומדביקים את המספרים.

**המכרה**
- מנהרות ואולמות מסלע טבעי: שדה מרחק (SDF), רעש סלע, Surface Nets ברזולוציה של 30 ס"מ
  (בערך 325 אלף פוליגונים), ועוד displacement בזמן רינדור לפרטים של מילימטרים.
- **חומר קרקע של 4 שכבות** (סלע מערה / חול / סלע מחצבה / עפר מחצבה) לפי צבעי vertex. זה בדיוק הרעיון
  של ה-shader `terrain_cb_w_4lyr` של GTA. החול מתמלא קודם בחלקים הנמוכים של הסלע (height blend).
- **רצפת חול אמיתית**: גרגרים, חצץ, אדוות, 260 אלף אבנים קטנות, שברי סלע ליד הקירות, מאות **טביעות רגליים**
  בחול לאורך המסלולים, וקירות רטובים ליד הרצפה.
- מסגרות עץ (עמודים, קורה עגולה, תמוכות, קרשי תקרה) כל 3.6 מ', מסילות עם פרופיל אמיתי, אדנים ופלטות,
  עגלות כרייה, מנורות עבודה עם כלוב וזכוכית, כבלים, שרשראות נורות באולמות, מגדלי פרוז'קטורים,
  צינור אוורור, פיגום וסולם, נטיפים וזקיפים.
- 35 עורקי עפרה **בדיוק** בנקודות שהסקריפט של FiveM מספאון בהן עפרות, ואולם גבישים זוהרים.
- בית המלאכה: כבשן לבנים עם דלת פתוחה, ארובה ואש, ערימת פחם, 2 מקדחות עמוד לפיצוח, 2 שולחנות תכשיטים
  עם מנורה, מלחציים ואבני חן, דלפק חנות עם מדפים, ארגזים ומכושים, ושולחן קונה עם משקל ומטילי זהב.
- חוץ: שמש ושמיים פיזיקליים (Nishita). בפנים: נורות להט חמות ואבק באוויר.

**הכול מיושר עם הסקריפט**: `(0,0,0)` = ה-origin של ה-MLO (`2889.014, 2664.655, 41.72483`), והמחולל בודק
שכל 43 נקודות האינטראקציה (35 עפרות, תחנות, NPC-ים, כניסה) עומדות בחלל פתוח:

```
[cave] validation: 43/43 FiveM points stand in open cave
```

## טקסטורות 4K

כל שכבת קרקע נאפית (bake) לסט **4K seamless**: `albedo`, `roughness`, `height`, `normal`.
הטקסטורות נבנות על טורוס 4D, ולכן חוזרות על עצמן בלי תפר. עם הטקסטורות האפויות הרינדור הרבה יותר מהיר,
ואותם קבצי PNG נכנסים ישר ל-ytd של GTA.

| שכבה | גודל אריח |
|---|---|
| `cave_rock` – סלע גיר שבור בפאות, סדקים, צל בשקעים | 5 מ' |
| `cave_sand` – חול, גרגרים, חצץ, אדוות | 3 מ' |
| `quarry_rock` – קיר פיצוץ עם עקבות קידוח אנכיות | 8 מ' |
| `quarry_dirt` – עפר מחצבה, חצץ, סדקי יובש | 5 מ' |

## הרצה

**בתוך Blender 4.x:** Scripting → Open → `cave_mine_generator.py` → Run Script (בערך דקה וחצי).

**בלי ממשק** (מומלץ, כולל אפייה ורינדור 4K):

```bash
# 1) אפייה של הטקסטורות 4K (פעם אחת, בערך 20 דקות) + בניית הסצנה + שמירה
blender -b -P cave_mine_generator.py -- --bake textures/ --save cave_mine.blend

# 2) רינדור כל המצלמות ב-4K
blender -b -P cave_mine_generator.py -- --render previews/ --res 3840x2160 --samples 96

# תצוגה מהירה
blender -b -P cave_mine_generator.py -- --fast --render quick/ --res 1280x720 --samples 24
```

(`python cave_mine_generator.py ...` עובד באותה צורה עם `pip install bpy==4.2.0`.)

| אפשרות | מה זה עושה |
|---|---|
| `--bake DIR` / `--bake-size 4096` | אפייה של הטקסטורות (ברירת מחדל 4K) |
| `--textures DIR` | שימוש בטקסטורות שנאפו קודם (ברירת מחדל: `textures/` ליד הסקריפט) |
| `--render DIR` / `--only a,b` | רינדור כל המצלמות / רק חלק מהן |
| `--res` / `--samples` | רזולוציה (ברירת מחדל 3840x2160) / samples |
| `--fast` | בלי displacement ועם פחות אבנים, לתצוגה מהירה |
| `--save FILE.blend` | שמירת הסצנה |

`label_overview.py` הופך את מפת העל (`07_overview.png`) למפה עם שמות, נקודות העפרה והתחנות.

## ל-GTA / FiveM (Sollumz)

1. להתקין [Sollumz](https://github.com/Sollumz/Sollumz) ב-Blender.
2. `Cave_Shell`: לחלק לפי אזורים (כניסה, אולם, מנהרות, בית מלאכה) ולהמיר כל חלק ל-Drawable עם
   `terrain_cb_w_4lyr`. ה-vertex colors `Layers` הם המשקלים של 4 השכבות, והטקסטורות האפויות הן ה-ytd.
3. **התנגשויות**: `Cave_Collision` (עותק מופחת). את הרצפה (פאות שפונות למעלה) לסמן כ-`SAND_LOOSE`,
   ואז במשחק יש טביעות רגליים ואבק כשהולכים. את הקירות לסמן `ROCK`. חלק המחצבה בחוץ כבר קיים ב-GTA
   (אפשר למחוק אותו לפני הייצוא).
4. ליצור Archetype מסוג MLO עם Rooms + Portal בפתח, למקם ב-origin שלמעלה, ולייצא ytyp + ymap.
5. `urban_cavemining` עובד עם המודל הזה כמו שהוא: העפרות והתחנות כבר יושבות במקום.
